### Supported Browsers
- ✅ **Chrome** (Recommended) - Version 90+
- ✅ **Firefox** - Version 88+
- ✅ **Microsoft Edge** - Version 90+
- ✅ **Safari** - Version 14+ (Mac only)

- **JavaScript:** Must be enabled
- **Cookies:** Must be enabled
- **Screen Resolution:** 1024x768 minimum (1366x768 recommended)
