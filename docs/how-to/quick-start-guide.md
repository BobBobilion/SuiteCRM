# F&I Deal Center Quick Start Guide

## Get Up and Running in 15 Minutes

---

**For:** New Users, Sales Staff, F&I Managers  
**Time Required:** 15 minutes  
**Prerequisites:** SuiteCRM login credentials

---

## Step 1: Access the System (2 minutes)

### Login and Navigate
1. **Open** your web browser
2. **Go to** your SuiteCRM URL
3. **Login** with your credentials
4. **Click** "F&I Deal Center" in the main navigation

### What You'll See
- Deal list view with existing deals
- "Create F&I Deal" button (top right)
- Module menu with Calculator, Reports, Analytics

---

## Step 2: Try the Payment Calculator (5 minutes)

### Quick Calculator Test
1. **Click** "Payment Calculator" in module menu
2. **Enter** these sample values:
   - **Vehicle Sales Price:** $25,000
   - **Down Payment:** $5,000
   - **Interest Rate:** 6.5%
   - **Loan Term:** 60 months

3. **Watch** the real-time calculations:
   - Amount Financed: $20,000
   - Monthly Payment: ~$392
   - Total of Payments: ~$23,520

4. **Click** "Payment Scenarios" to see all term options
5. **Try** changing the interest rate to see payment changes

### Key Learning
✅ All calculations happen instantly as you type  
✅ Payment scenarios help compare different terms  
✅ Calculator works without saving any data

---

## Step 3: Create Your First Deal (8 minutes)

### Basic Deal Creation
1. **Click** "Create F&I Deal" from main menu
2. **Fill** minimum required fields:
   - **Deal Number:** TEST001
   - **Customer:** Select existing or type new name
   - **Sales Price:** $25,000

3. **Navigate** to "Financing" tab
4. **Enter** financial details:
   - **Down Payment:** $5,000
   - **Interest Rate:** 6.5%
   - **Term:** 60 months

5. **Watch** automatic calculations:
   - Amount Financed calculates automatically
   - Monthly Payment appears in real-time
   - All dependent fields update instantly

### Save Your Work
1. **Click** "Save" button
2. **Note** the deal is saved as "Draft" status
3. **Click** "Payment Scenarios" to test modal popup
4. **Review** the professional interface layout

### Key Learning
✅ Real-time calculations in EditView  
✅ Professional tabbed interface  
✅ Automatic field relationships  
✅ Data persistence across sessions

## Quick Reference

### Most Important URLs
- **Calculator:** `index.php?module=DM_FIDeals&action=calculator`
- **New Deal:** `index.php?module=DM_FIDeals&action=EditView`
- **Deal List:** `index.php?module=DM_FIDeals&action=index`

### Essential Buttons
- **"Payment Scenarios"** - Compare different loan terms
- **"Recalculate"** - Refresh all calculated fields
- **"Save"** - Preserve your work
- **"F&I Products"** - Add warranties and insurance

### Common Calculations
- **Amount Financed** = Sales Price - Down Payment - Net Trade Equity + Taxes/Fees
- **Net Trade Equity** = Trade Allowance - Trade Payoff
- **Monthly Payment** = Uses standard loan payment formula
